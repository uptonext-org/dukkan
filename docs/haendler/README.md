# Händler-Leitfaden

Kurzanleitung für Märkte: Konto, Markt anlegen, Produkte, Online-Bestellungen, Bestellungen
bearbeiten, Aktionen, Pflichten (kein Alkohol und Tabak, Allergene, Impressum).

| Sprache | Datei |
|---|---|
| Deutsch | [leitfaden-de.md](leitfaden-de.md) |
| Türkçe | [leitfaden-tr.md](leitfaden-tr.md) |
| العربية | [leitfaden-ar.md](leitfaden-ar.md) |

Die Schaltflächen heißen wie in App und Portal (Stand 28.10.2026). App und Portal gibt es auf Deutsch,
Englisch und Arabisch; der türkische Leitfaden nennt die deutschen Bezeichnungen mit Übersetzung.
Platzhalter in [eckigen Klammern] (Portal-Adresse, Support-Kontakt, Prüfdauer) vor dem Verteilen
ausfüllen. Als PDF: z. B. `pandoc leitfaden-de.md -o leitfaden-de.pdf`; für Arabisch eine Vorlage mit
Rechts-nach-links-Satz verwenden.
